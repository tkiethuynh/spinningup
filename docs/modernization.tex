\subsection{Deep Learning Frameworks}

\subsubsection{PyTorch 2.x Optimization}
PyTorch implementations now utilize the full stack of version 2.x features:
\begin{itemize}
    \item \textbf{Graph Compilation:} Use of \texttt{torch.compile(model)} for kernel fusion and optimized execution.
    \item \textbf{Eager Dispatch:} Automatic device placement for all tensors.
    \item \textbf{Type Safety:} Full type hinting for complex actor-critic signatures.
\end{itemize}

\subsubsection{TensorFlow 2.x Migration}
The TF implementation was rewritten from the ground up to remove legacy \texttt{tf.Session} and \texttt{tf.placeholder} dependencies.
\begin{lstlisting}[language=Python, caption=Modern TF2 Gradient Tape Pattern]
with tf.GradientTape() as tape:
    loss_pi, kl, ent = compute_loss_pi(obs, act, adv, logp_old)
grads = tape.gradient(loss_pi, ac.pi.trainable_variables)
pi_optimizer.apply_gradients(zip(grads, ac.pi.trainable_variables))
\end{lstlisting}

\section{Hardware Acceleration and Device Resolution}
The project features a revolutionary \textbf{Dynamic Library Resolution} system.

\subsection{NVIDIA Pipeline Coordination}
To solve the conflict between pip-installed NVIDIA libraries and framework requirements, the system executes a real-time symlink strategy:

\begin{enumerate}
    \item \textbf{Discovery:} Scans \texttt{sys.path} for \texttt{nvidia-*} packages.
    \item \textbf{Translation:} Maps \texttt{libcudnn.so.9} $\rightarrow$ \texttt{libcudnn.so.8}.
    \item \textbf{Injection:} Updates \texttt{LD\_LIBRARY\_PATH} before the first C++ backend load.
\end{enumerate}

\section{MPI and Distributed Execution}
MPI support has been modernized to coordinate correctly with GPU devices. In distributed runs, the system ensures that each MPI process:
\begin{itemize}
    \item Synchronizes weights across ranks using \texttt{broadcast}.
    \item Averages gradients globally before optimizer steps.
    \item Prevents redundant GPU memory allocation via \texttt{allow\_growth} settings.
\end{itemize}
