\section{Introduction}
This document details the modernization efforts applied to the OpenAI Spinning Up in Deep RL repository. The project has been updated to support contemporary Python environments, latest deep learning frameworks (PyTorch 2.x and TensorFlow 2.x), and modern RL environment standards.

\section{Core Modernization Pillars}

\subsection{Environment API: Gymnasium}
The repository has transitioned from the legacy \texttt{gym} library to \texttt{gymnasium}. 
\begin{itemize}
    \item Updated \texttt{env.step()} to handle the new return signature: \texttt{obs, reward, terminated, truncated, info}.
    \item Updated \texttt{env.reset()} to handle: \texttt{obs, info}.
    \item Replaced all \texttt{import gym} with \texttt{import gymnasium as gym}.
\end{itemize}

\subsection{Framework Updates}
\subsubsection{PyTorch 2.x}
\begin{itemize}
    \item Integrated \texttt{torch.compile} for optimized execution graphs.
    \item Added support for GPU/CUDA device placement.
    \item Fixed device-specific errors by ensuring proper \texttt{.detach().cpu().numpy()} calls.
\end{itemize}

\subsubsection{TensorFlow 2.x}
\begin{itemize}
    \item Complete migration from TensorFlow 1.x (Session/Placeholder based) to TensorFlow 2.x using Keras models and Eager Execution.
    \item Utilized \texttt{tf.GradientTape} for gradient calculation.
    \item Implemented custom MPI-aware optimizers compatible with TF2.
\end{itemize}

\subsection{Device Management and GPU Acceleration}
A framework-agnostic device management system has been implemented in \texttt{spinup.utils.device\_utils}. This module ensures that both PyTorch and TensorFlow 2.x utilize available hardware acceleration.

\subsubsection{NVIDIA Library Dependency Resolution}
A significant challenge in modernizing the repository was the version mismatch between pip-installed NVIDIA libraries (e.g., cuDNN 9) and the specific versions expected by TensorFlow 2.15 (e.g., cuDNN 8). To resolve this, a dynamic library mapper was implemented. This strategy:
\begin{itemize}
    \item Scans the user's \texttt{site-packages} for NVIDIA-provided shared objects.
    \item Creates version-mapped symbolic links in a localized \texttt{tf\_gpu\_libs} directory.
    \item Dynamically injects these paths into \texttt{LD\_LIBRARY\_PATH} at runtime.
\end{itemize}
This ensures that the repository remains "plug-and-play" across diverse Linux environments with standard NVIDIA drivers.
